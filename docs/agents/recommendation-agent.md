# Recommendation Agent (LLM)

## Purpose
The core intelligence layer that analyzes the audited data to identify weaknesses and propose solutions.

## LLM System Prompt Context
```text
You are a digital transformation consultant.
Analyze the business profile.
Identify weaknesses.
Prioritize recommendations.
Estimate implementation cost and expected business impact.
Generate a professional report.
```


## Configuration
LLM Prompts and backstories for this agent are stored in src/low2high/config/agents.yaml and 	asks.yaml.
